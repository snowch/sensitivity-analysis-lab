Lesson 1 of 4

Rank the pipeline inputs

Use a simulated pipeline to decide which two of its 13 inputs you would investigate first.

Simulate pipeline jobs

A pipeline fetches, processes and writes data. A job is one item of work that goes through those stages. Its latency is the time it takes to finish. Payload size is the amount of data in a job.

A cache can serve a stored copy and save time. The cache hit rate is the percentage of requests served this way.

A Monte Carlo simulation draws values from assumed input ranges and calculates latency for each draw. The model samples each input independently, so drawing one value leaves the other inputs’ chances unchanged. Within each range, equal-width intervals are equally likely.

Read the direction of the relationship

Spearman rank correlation compares two orders of the same jobs, one by input value and one by latency.

  • Near +1. Higher input values tend to go with longer jobs.
  • Near −1. Higher input values tend to go with shorter jobs.
  • Near zero. There is little consistent ordering. Check for an effect that changes direction before ruling out the input.

Which two inputs would you investigate?

Spearman scores

Find the two longest bars. Record the input names and whether each score is positive or negative. Of the two inputs with the longest bars, which one has a negative score, meaning higher values of that input tend to go with shorter jobs?

Check another seed

Open Simulation settings. Set Random seed to 19 and leave Simulated runs at 8192. Select Run simulation again. In Top two across runs, compare First input and Second input for seeds 42 and 19. Did the names or signs change?

Read the result

In this model, cache hits avoid slower fetches and larger jobs take longer to process. Changing the seed draws a different sample from the same ranges. Check whether the top two stay the same before interpreting small score changes.

Reveal the two highest-ranked inputs for seed 42

At seed 42 and 8,192 jobs, cache hit rate leads at −0.84 and payload size follows at +0.51.

A small score can conceal a strong effect that changes direction. For example, fuel use can rise both below and above an efficient speed. Plot the input against the output before you rule it out.
