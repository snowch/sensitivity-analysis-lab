Lesson 1 of 4

Rank the pipeline inputs

Use a simulated pipeline to decide which two of its 13 inputs you would investigate first.

A pipeline fetches, processes and writes data. Here a job is one item of work that passes through those stages. Its latency is the time it takes to finish. A cache serves a stored copy without fetching the data again. The cache hit rate is the percentage of requests served from that copy. Payload size is the amount of data in a job.

A Monte Carlo simulation draws values from assumed input ranges and calculates latency for each draw. The model samples each input independently, so drawing one value leaves the other inputs’ chances unchanged. Within each range, equal-width intervals are equally likely.

Spearman rank correlation sorts the jobs by one input and again by latency. A score near +1 means larger inputs usually go with longer jobs. A score near −1 means larger inputs usually go with shorter jobs. A score near zero means there is little consistent ordering in either direction. An input can still matter if its effect changes direction.

Which two inputs would you investigate?

  1. Leave the starting settings at 8,192 jobs and seed 42. Select Run simulation. In Spearman scores, find the two longest bars. Use each sign to say whether higher input values go with shorter or longer jobs.
  2. Open Simulation settings, change Random seed from 42 to 19, and select Run simulation again. A seed sets the sequence of draws. In Top two across runs, compare the input names and their signs for seeds 42 and 19. Did your shortlist change?

Read the result

In this model, cache hits avoid slower fetches and larger jobs take longer to process. Changing the seed draws a different sample from the same ranges. Check whether the top two stay the same before interpreting small score changes.

Reveal the two highest-ranked inputs for seed 42

At seed 42 and 8,192 jobs, cache hit rate leads at −0.84 and payload size follows at +0.51.

A small score can conceal a strong effect that changes direction. For example, fuel use can rise both below and above an efficient speed. Plot the input against the output before you rule it out.
