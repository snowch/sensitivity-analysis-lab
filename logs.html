Work from logs

Use synthetic pipeline records to see which inputs help predict job delays.

Test on jobs the model hasn’t seen

On the first run, the page generates 10,000 synthetic pipeline records. It trains a random forest on 8,000 rows and tests it on the other 2,000. New shuffles during this visit reuse the fitted forest and test rows.

A forest averages predictions from decision trees, which split data into groups. The mean absolute error (MAE) is the average distance between predicted and recorded latency, in milliseconds.

Shuffle one signal and measure the error again

Permutation importance shuffles the values in a test column and predicts again with the same model. Recorded latencies and the other columns stay in place. An increase in MAE shows how much accuracy the model loses when the shuffled values stop matching their jobs.

Read the result

An edge cache stores copies close to users. Edge miss rate is the share of requests with no usable copy there. Origin fetch rate is the share that had to reach the original source.

The synthetic data make both noisy measures of the same cache behaviour. Shuffling one leaves the other available. Moving both together keeps them aligned with each other while breaking their link to the original jobs.

The chart describes which signals help this predictor on these test rows. To test whether a change helps the pipeline, compare the same workload under two settings, such as current and increased worker capacity. Decide in advance which latency and cost measurements would justify the change.

How the synthetic data and predictor are prepared

The data include noisy latency measurements, blanks in the two cache counters and an irrelevant deployment-age column. The page fills blank values with medians calculated from the training rows. The forest averages predictions from 24 trees fitted on resampled training rows.

The output reports the mean change in error and how much that change varies across shuffles on the same test set. See the data generator and evaluation code.
